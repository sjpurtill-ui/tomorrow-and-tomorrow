# Representative work landscape art

These illustrations provide context for the nine workforce activities. They do
not assert that a specific building exists, a technology is unlocked, or a stock
is available. The renderer contains no painted humans; the dynamic cast owns
every representative.

Generated with the built-in imagegen tool, October 15, 2026. Both outputs use
true alpha transparency and a warm painted strategy-game style viewed from a
fixed elevated camera. Original generated files remain outside the repository.

- `work-world-sites-v1.png`: six equal cells, three columns by two rows. Fields;
  rocky survey ground; wood and stone yard; learning circle; empty care shelter;
  watch platform with stone-point spears. Prompt required early natural materials,
  no metal machinery, no people, no text, no rectangular backgrounds. A subsequent
  image edit reduced each object inside its cell and made all cell boundaries
  fully transparent. The automated alpha-gutter test verifies those boundaries.
- `work-world-well-v1.png`: one low rough-stone well with cord, timber supports,
  a wooden bucket, woven carrying baskets, and a trough. Prompt required no
  people or animals, no metal fittings, and transparent surroundings.

The landscape reuses the existing painted workshop, building frame, meadow and
foliage assets. Slot and transfer-path geometry is authored separately so the
art does not determine worker counts or game behavior.
