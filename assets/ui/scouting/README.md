# Ancient scouting window artwork

The expedition, clay surface and selected-stone illustration come from the original accepted ancient-scouting-council mockup (September 10, 2026). These are intentional window artwork, not a view of the current map or a literal census of a party. The find image is used only for a returned Stone Selection specimen or artifact; other objects use an honest type symbol.

Original generation sources remain outside the repository in the thread generated_images directory. These three JPEGs are the exact approved mockup assets, not new crops of unrelated discovery art. Do not reuse the selected-stone image for pottery, oral traditions or generic discoveries.

The bundled Cinzel typeface comes from https://github.com/google/fonts/tree/main/ofl/cinzel and carries its SIL Open Font License alongside the font. Gameplay needs no font download.
