# Production illustrations

`workshop-atlas.png` is a 4 × 3 sheet generated with the built-in image-generation tool. Godot uses atlas regions without rewriting pixels. This is the initial illustrated family, not full product-catalog artwork coverage. Unmapped items deliberately use the workbench symbol. The final asset has an ivory background; the requested transparency was not produced.

Generation prompt:

Create a polished game UI asset atlas, transparent background, 1536x1024 landscape. EXACTLY 4 columns and 3 rows of equal sized cells, evenly aligned grid, no lines no text no labels. Each illustration completely contained centered in its cell with 15% empty margin. Antique naturalistic gouache object cutouts matching a premium light parchment historical strategy game. Earth colors warm gray ochre brown linen muted copper; crisp silhouettes delicate hand painted texture. Transparent around every object, no card backgrounds, no shadows extending beyond cells. Row1 left to right: three long horizontal wooden spears with clearly STONE flint spearheads; three unglazed earthenware vessels; folded woven flax cloth with spindle; wooden hunting bow and arrows. Row2 left to right: two-wheel wooden handcart; two copper axes/adzes; small bundle of three cut timber logs; coiled raw plant fiber. Row3 left to right: rough gray stone pieces; two raw clay lumps; rough copper ore nuggets; wooden craftsman's workbench with small neutral tools (generic workshop symbol). Maintain identical lighting and artistic weight across all 12 isolated illustrated assets. No humans, no modern machines, no words, no interface. Strict 4x3 equal grid atlas on fully transparent background.

Final edit prompt (applied to the first generation):

Replace ONLY the brown gradient background with a completely flat, uniform, pale warm ivory background color #F2EADC. Every background pixel must be pale ivory, no brown gradient, no halos, no shadows. Preserve exactly all objects and 4 columns by 3 rows grid. This needs to sit on a light parchment UI. Bright flat ivory background everywhere between objects. No text.
