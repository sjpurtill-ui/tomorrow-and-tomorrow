# Bronze and early Iron Age key thresholds: final set

Thirteen paintings generated with built-in image generation on 2026-09-26,
completing the inventory's 37 late Bronze / Iron Age key thresholds alongside
the prior two 12-painting batches. Each painting has a companion provenance
JSON with its original output file and SHA-256 hash.

## Prompt set

Each prompt specified a wide 3:2 mature handmade editorial painting, its
historical mechanism, and the medium from `art_direction_styles.json`. We
excluded photography, CGI, cinematic realism, childlike figures, modern tools,
text, pseudo-writing, logos, emblems, and borders. The crop sheet shows each
selected central 3.37:1 game banner.
