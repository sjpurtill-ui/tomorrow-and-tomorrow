# Bronze and early Iron Age key thresholds: second set

Twelve game paintings generated with built-in image generation on 2026-09-26.
The selected paintings follow `data/research/art_direction_styles.json` and
the subjects' research descriptions. Each installed PNG has a companion JSON
file recording its original output path, source hash, line, and art medium.
`selected-banner-crops.png` shows the central 3.37:1 crop used for selection.

## Prompt set

Common requirements: mature 2D handmade editorial art, 3:2 landscape, period
appropriate people and tools, clear central action. Exclusions: photography,
CGI, cinematic realism, childlike proportions, modern objects, text,
pseudo-writing, logos, emblems, and borders. Reference images were provided
only to maintain each research direction's visual medium and palette.

| Id | Selected prompt focus |
|---|---|

the prior batch. The selected versions use different staging. Only the PNGs
in `assets/ui/research/subjects` are referenced by the game manifest.
