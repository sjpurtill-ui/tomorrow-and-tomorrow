# Earliest key-threshold research paintings

Generated with built-in image generation on 2026-09-26. These twelve selected
paintings are one per research direction in `y600_1200`. Source filenames and
SHA-256 hashes are recorded beside each installed PNG in `subjects/<id>.json`.
`selected-banner-crops.png` shows the intended central 3.37:1 game crop.

## Prompt set

Each prompt specified a wide 3:2 landscape illustration for the mature game,
the event or mechanism below, its period, and the corresponding medium in
`data/research/art_direction_styles.json`. The common exclusions were
photography, CGI, cinematic realism, childlike proportions, modern objects,
text, invented script, logos, seals, borders, and watermarks. Several first
variants were rejected for realistic rendering or anachronistic clothing.

| Direction | Selected subject and prompt focus |
|---|---|
| Institutions | `palace_department_registers`: distinct palace bureaus recording flocks, fields, workshops, and rations on tablets in matte civic fresco. |
| Demography | `overseas_colony_founding`: elders farewell young adults boarding a simple square-sail boat; angular chalk pastel and cut-paper collage. |
| Health | `incubation_shrines`: care for a resting sick adult with spring water in a simple Bronze Age open-air sanctuary; sage watercolor and light ink. |
| Logistics | `brailed_square_sail`: crew pull brail ropes from deck to shorten a square sail; panoramic travel watercolor. |
| Labor | `forge_crew_roles`: master holds iron in tongs, striker raises hammer, apprentice works bellows; charcoal over ochre wash. A directed edit corrected first-variant modern workwear. |
| Nutrition | `iron_ard_shares`: oxen pull an iron-tipped ard through clay and roots; botanical egg tempera. |
| Ecology | `smelter_fuel_depletion_watch`: observer watches cutting near iron fuel production and a rested woodland; naturalist plant-pigment painting. |
| Culture | `lost_age_remembrance`: singer recounts fallen palaces and past heroes to a gathered community; tapestry-inspired painting. |
| Security | `iron_sword_issue`: smith distributes iron blades to guards; vermilion and charcoal woodblock print. |
