# Retired illustrated landmarks

The named landmark system has been removed from gameplay at the user's request. This archive preserves the original Midjourney artwork and 195-feature prompt sheet. Godot ignores this directory; the images are no longer imported or displayed in the game.

Removed: feature generation, named map labels, detail pop-ups, myth cards, scouting-range bonuses, and landmark save fields. Older saves discard landmark discovery cards and related journal lines while retaining resource discoveries, contacts, routes, and supplies.
