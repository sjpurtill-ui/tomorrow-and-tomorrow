# Landmark Feature Illustrations — Midjourney Prompt Sheet

195 terrain-derived landmark features. Each becomes a pop-up illustration shown when the
player clicks the landmark on the map. Save each finished image as
`assets/textures/landmarks/<feature id>.png` and the game can key them directly.

Names containing an adjective slot are shown with 'Grey' as a placeholder — the game
substitutes one of fifteen adjectives at naming time, so keep imagery adjective-neutral.
