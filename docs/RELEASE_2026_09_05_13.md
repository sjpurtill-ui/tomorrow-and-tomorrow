# Release 2026.09.05.13: understandable scouting and army routes

Scouting has one expedition planning entry, actual elapsed days in return prose,
estimated due dates instead of ambiguous progress, and explanations distinguishing
rumors, encounters and located settlements. Terrain-blocked searches show the full
reason and suggest shorter trips or another heading before committing anyone.

Army orders check authoritative land along the direct route before changing orders.
A newly blocked route stops the army and sends a runner; reported reasons stay
subject to report delay. Low supply explains reduced pace and points to Supply.
Map actions now display readable feedback above the toolbar instead of relying on
a ticker obscured by panels. Direct routes use bounded samples, not a pathfinder.

Validation: 130/130 cases in nine suites, zero exit status, in
artifacts/release-thirteen-checked-tests.log. Actual GPU coastal-order and low-supply
journey: field-disruption-visible.log. First natural scout return and archive:
scout-readability-second.log. Continuous genuine world: first return day45,
long return day522, then terrain-blocked east365 recovered via east90 and returned
day612 (coherent-east-readable-final.log). No foreign contacts; diplomacy is not
claimed verified by this continuous run. Coastal placement is an authored fixture.
The GPU helper now accepts an explicit frame budget for long simulations; default
short-probe behavior is unchanged. Completion markers, not exit0 alone, establish
probe completion.

Private test data and captures remain outside commits. Canonical player/save are
preserved; the loaded .6 player needs normal save/exit and the canonical launcher
to load .13. No forced restart or save migration was performed.
