# Microprogrammed machine control

Four authored discoveries extend stored-program control: diode control stores, microinstruction sequencing, arithmetic-logic units and microprogrammed machine control. Their causal paths reconverge through existing diode logic, decoders, counters, conditional branches, adders, inverters and register banks. Day zero on each entry means no calendar unlock gate.

Control Stores, Microsequencers and Arithmetic-Logic Units are separately manufactured from existing electronics. An alternative controller recipe combines all three with read-write memory, an electronic machine interface and cable. Its output is the existing Programmable Controllers stock, consumed by the commissioned programmable workshop. The original stored-program controller recipe remains available. Both routes provide the same current operational capability: powered workshop service still needs actual electricity, operators and commissioning. No instructions execute merely because a discovery is known.

[Wilkes and Stringer's original account of microprogramming](https://gordonbell.azurewebsites.net/Computer_Structures__Readings_and_Examples/00000355.htm) describes sequencing control operations through stored control information. The implemented separation between control store, sequencing and datapath follows that architectural distinction. It does not assert that microprogramming universally follows every particular historical hardware design.

All material quantities are game batches. Final assembly takes four worker-days versus eight for the earlier recipe, but the separately fabricated subassemblies have their own materials and work costs. This is not a claim that total cost or speed is universally superior. The present stock model treats completed controllers as interchangeable and does not simulate instruction sets, clock rates, microcode execution, writable firmware, patching, emulation, integrated-circuit fabrication or modern processor performance. A diode control store here is fixed by manufacture. No new installation type or save fields are added; new discovery and recipe IDs require this revision. Existing records remain compatible. Manufacturing licenses and ordinary shared Crafting work apply through the existing production system.

Modern and future coverage remains incomplete. This is an implemented computing foundation, not a claim that the modern or future eras are finished.
