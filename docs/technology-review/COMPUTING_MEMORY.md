# Physical memory and stored-program control

Eight authored discoveries extend the existing digital-logic branch: Relay Registers, Parallel Register Banks, Memory Address Decoding, Addressable Read/Write Memory, Instruction Registers, Program Counters, Conditional Branch Circuits and Stored-Program Control. They have causal foundations and no calendar eligibility gates. Relay and electronic registers reconverge at read/write memory. Address decoding also admits relay or diode logic; a relay decoder recipe avoids forcing transistor parts into the relay-memory path.

Ten civilian recipes produce Relay Registers, Register Banks, Memory Decoders, Read-Write Memory, Instruction Registers, Program Counters, Branch Units and Programmable Controllers. Decoders and read/write memory each have two component routes. Relay assemblies use relays, logic and copper wiring; electronic assemblies use bistables, inverters and related existing components. A final controller consumes one each of memory, instruction register, program counter, branch unit, Electronic Controller and Insulated Cable, plus paid workshop tooling and eight work. These are equipment batches, not stored information or free research.

The seventh operating plant, Programmable Machine Workshop, requires adopted Stored-Program Control and Electric Motors. Installation consumes one Programmable Controller, one Electric Motor, two Insulated Cable and three Steel, then twenty commissioning work. Full operation reserves 1.5 Crafting workers and consumes four daily electricity to provide six mechanical-work service. Solar generation remains a viable route. Existing health, staffing, shared-power limits and bounded mechanical assistance still apply. This improves output per operator over hardwired sequencing at a greater electrical demand; it does not replace the earlier plant automatically.

The [Computer History Museum's stored-program exhibit](https://www.computerhistory.org/revolution/birth-of-the-computer/4/87) describes instructions held in memory rather than encoded only by external wiring. Its [transistor memory history](https://www.computerhistory.org/storageengine/transistors-make-fast-memories/) covers bistable electronic storage. The [archived processor reference](https://archive.computerhistory.org/resources/access/text/2016/12/102762484-05-01-acc.pdf) explains program-counter fetch, instruction decoding and conditional transfer. Dependencies and resource/work coefficients here are game design choices, not a chronology lock or a circuit bill of materials.

Limits: there is no simulated instruction set, bit width, memory contents, clock timing, instruction loading, software authoring, error correction or program-specific control task yet. The operating effect represents a commissioned controller using an established workshop routine. Memory assets are hardware; their stock does not imply that bits persist without power. Relay/electronic memory outputs currently share the same aggregate equipment category, without retained supplier or circuit provenance. This is not a claim to have implemented general computing, magnetic memory, integrated circuits or later software history.

Save schema is unchanged. New plant/recipe IDs require this implementation. Aggregate bounds expand to 14,000 simultaneous commissioning workers and 18,500 mechanical-work service across all seven maximum-size plant categories; existing electrical and cold-storage bounds remain unchanged. AI power planning reads the added consumer's demand, but automatic construction of consumer plants remains unfinished.
