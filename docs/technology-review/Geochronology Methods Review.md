## Tree-Ring Crossdating

Seasonal observation recognizes recurrence; crossdating resolves correspondence between retained annual sequences. A climate interpretation still requires proxy calibration.

Implementation must demonstrate: Introduce a missing or false ring and require inconsistent matches to be flagged; no calendar year appears without an anchored reference.

Evidence: [Institutional method reference 1](https://www.nps.gov/articles/archeology-dendrochronology.htm), [Institutional method reference 2](https://oceanservice.noaa.gov/education/dyw-tree-detective.html).

## Varve Chronology Correlation

Core reconstruction preserves sequences; this specifically tests annual layer correspondence and accumulated counting uncertainty.

Implementation must demonstrate: A missing core interval remains a gap; a storm layer cannot be counted as a year solely because it is visible.

Evidence: [Institutional method reference 1](https://water.usgs.gov/wrri/grant-details.php?ProjectID=2008CA243B&Type=Annual).

## Radiocarbon Calendar Calibration

General isotope geochronology does not equate conventional radiocarbon years to calendar years. A sample date is not automatically the age of its surrounding artifact or water body.

Implementation must demonstrate: Retain separate probability ranges where the curve permits multiple dates; changing reservoir evidence must change or invalidate the result.

Evidence: [Institutional method reference 1](https://cmgds.marine.usgs.gov/catalog/spcmsc/FL_keys_radiocarbon_reservoir_age_variability_metadata_Marine20.faq.html), [Institutional method reference 2](https://pubs.usgs.gov/pp/pp1661f/pp1661f.pdf).

## Luminescence Sediment Dating

Measures accumulated trapped charge rather than a parent/daughter isotope ratio. Sample exposure during collection can destroy the relevant record.

Implementation must demonstrate: A light-exposed or incompletely reset sample must not yield the same accepted burial date as a qualified specimen; dose-rate uncertainty propagates.

Evidence: [Institutional method reference 1](https://www.usgs.gov/labs/luminescence-dating-laboratory/luminescence-dating-laboratory), [Institutional method reference 2](https://www.usgs.gov/publications/guide-interpreting-and-reporting-luminescence-dating-results).

## Cosmogenic Surface Exposure Dating

Near-surface production is part of this clock, unlike a generic closed decay system; it does not directly date initial rock crystallization.

Implementation must demonstrate: Changing documented cover or inherited concentration changes the inferred interval; the method cannot reveal an unvisited surface.

Evidence: [Institutional method reference 1](https://www.usgs.gov/publications/dating-cosmogenic-nuclides).

## Paired-Nuclide Burial Histories

Adds a two-nuclide history constraint, not another name for a single surface-exposure clock.

Implementation must demonstrate: Withhold a unique burial duration when two incompatible histories fit the observations; one isotope alone cannot satisfy the method.

Evidence: [Institutional method reference 1](https://www.usgs.gov/publications/dating-cosmogenic-nuclides).

## Fission-Track Thermochronology

Track damage and its thermal shortening are the observations; a track age alone is not a universal crystallization date or exact peak temperature.

Implementation must demonstrate: Different track-length distributions at similar apparent ages must affect the allowed history; unsupported annealing calibration prevents a precise reconstruction.

Evidence: [Institutional method reference 1](https://www.usgs.gov/publications/high-temperature-annealing-fission-tracks-fluorapatite-santa-fe-springs-oil-field-los), [Institutional method reference 2](https://www.usgs.gov/publications/fission-track-dating-apatite-and-zircon-interlaboratory-comparison).

## Argon Step-Heating Interpretation

A sequence of measured release fractions tests internal consistency beyond a bulk isotope age. It provides no automatic cooling or crystallization label.

Implementation must demonstrate: Discordant release steps cannot be silently averaged into a precise plateau; missing reference or blank evidence blocks qualification.

Evidence: [Institutional method reference 1](https://pubs.usgs.gov/publication/dr1227/full), [Institutional method reference 2](https://pubs.usgs.gov/bul/b2194/B2194-508.pdf).

## Review limits and integration requirements

The institutional sources support physical methods, not the proposed game prerequisites, numerical coefficients or hypothetical local supply. The varve source describes a particular research program, not proof that every sediment lamination is annual. The dated fission-track field study is evidence for model limitations, not a current universal calibration. No first-invention dates are assigned.

A runtime implementation must preserve sample identity, location, preparation loss, reference provenance, instrument or paid supplier capacity, failed qualifications and non-unique interpretations. An imported result must not create samples, knowledge or an exact geological history. Results must inform an actual geological reconstruction, hazard assessment or dated record while keeping conflicting evidence visible. Long geological ages describe the specimens, not elapsed gameplay or discovery calendar gates. All proposals retain existing world-state, daily labor and save owners.
