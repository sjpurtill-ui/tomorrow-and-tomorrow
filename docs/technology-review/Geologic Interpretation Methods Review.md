# Geologic interpretation methods

Six D22 proposals extend the catalog with distinct specimen interpretation methods. They do not change runtime 810. Worktree `/Users/seanpurtill/.codex/worktrees/ef8f/tomorrow-and-tomorrow`, branch `codex/geologic-interpretation-coverage`, base `1d4b4f986f14b55035f34b5a04ae93fe875d3588`. All named prerequisites are existing catalog identities; all six routes use AND requirements with no OR additions. Historical horizons remain unassigned.

| Proposed identity | Distinct evidence and intended use |
|---|---|
| `tephra_geochemical_correlation` | Compare actual ash-component composition and context across layers. An accepted correlation may transfer an independently established reference age; ambiguous matches remain ambiguous. The [USGS project account](https://www.usgs.gov/centers/gmeg/science/usgs-tephrochronology-tephra-project?page=1) describes sample preparation, compositional comparison and contextual checking. |
| `fossil_biostratigraphic_correlation` | Use identified assemblages and observed stratigraphic ranges to constrain relative correspondence between sections. Reworked fossils, barren intervals and regional differences limit interpretation. A [USGS study abstract](https://www.usgs.gov/publications/application-graphic-correlation-method-pliocene-marine-sequences) distinguishes relative fossil chronology and alternative correlation approaches. |
| `speleothem_uranium_series_chronology` | Interpret measured carbonate disequilibrium with a stated contamination correction and closed-system assumptions. This differs from radiocarbon calibration and cannot date an entire cave from one layer. The [Wind Cave data description](https://www.usgs.gov/data/uranium-thorium-strontium-carbon-and-oxygen-isotope-data-used-evaluate-a-300000-year-history) identifies measured U/Th data used for carbonate age estimates. |
| `helium_retention_thermochronology` | Use retained helium and measured parent elements with mineral-specific retention assumptions to constrain candidate thermal histories. The [USGS-hosted research abstract](https://pubs.usgs.gov/of/2007/1047/ea/of2007-1047ea193.pdf) discusses diffusion and cooling-history interpretation. It does not justify a universal closure temperature or a unique age of crystallization. |
| `fluid_inclusion_microthermometry` | Observe phase changes in retained inclusions using a calibrated microscope stage. The [USGS thermometric data report](https://pubs.usgs.gov/of/2004/1066/of2004-1066.html) concerns homogenization and salinity observations. An unconditional trapping temperature is not equivalent to a recorded phase-change temperature. |
| `carbonate_clumped_isotope_thermometry` | Compare measured isotope association with an attributable calibration and assess disequilibrium or later alteration. The [USGS publication abstract](https://www.usgs.gov/publications/beyond-temperature-clumped-isotope-signatures-dissolved-inorganic-carbon-species-and) explicitly discusses chemical influences beyond temperature. The proposal must preserve these interpretive limits. |

A purchased report is finite evidence, not discovery mastery. These methods do not create deposits, future climate knowledge or gameplay calendar gates. Existing broad stratigraphy, geochronology, petrography and proxy-calibration identities remain unchanged.
