## Remaining limitation

There is no peacetime city-trespass demand-to-leave system. Scout detection uses physical proximity, so field_position does not make the army invisible, but peaceful defenders do not currently issue a border challenge. A bounded follow-up should create a locally observed demand, a withdrawal deadline carried home through existing communication, and escalating diplomatic consequences. Whether ignored demands authorize defender-initiated force needs an explicit design choice; peaceful presence must not silently force a declaration. This release does not claim defender trespass behavior is solved.
