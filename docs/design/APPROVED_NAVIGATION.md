# Approved navigation reference — September 20, 2026

The user explicitly approved the sidebar icons and descriptors in
[the Wealth mockup](approved-wealth-and-navigation.png):
“Good and the side panel icon and descriptors are PERFECT on this one!”

Treat this image as the visual specification, not loose inspiration. Preserve
its narrow dark olive column, muted gold illustrated pictograms, short readable
labels beneath each symbol, aligned proportions, subtle dividers and olive/gold
active-row treatment. No letter initials, oversized tiles, or icon-only substitutes.

Approved labels in order: Overview, People, Food, Materials, Wealth, Buildings,
Production, Culture, Security. Preserve access to existing game functions when
mapping these labels; the reference does not authorize deleting unrelated systems.

Distribution is explicitly removed from the game navigation. Economy has three
tabs: Food & Water, Materials, Wealth. Dietary demand simulation is unaffected.

This is an approved design reference, not evidence of implemented navigation or
Wealth UI. Currency-era figures, portrait, terrain and illustrated trends are
sample design content. Early economies must use actual available records.
