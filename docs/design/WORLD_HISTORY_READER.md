# World history reader

World History now opens with three recent events and one complete selected telling. The archive replaces that overview with search, existing category filters and six results per page. Wide pages keep the results beside the telling. On a narrow page, choosing an archive result opens its telling in place with Back to results; search, filter and page remain intact. Back to recent events retains archive search/page for a later return.

All original Chronicle records, dates, occurrence counts, moment distinction and related-report callbacks remain available. The provider still supplies the same intelligence and record order; only the renderer and its refresh fingerprint change. Full text is readable in the selected telling rather than living solely in a tooltip. Scout and battle actions receive specific labels. No simulation, calculations, game state or save format changes.
