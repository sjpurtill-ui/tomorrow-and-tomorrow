# Production dependencies, years 1800–2400

Machine-readable source: `partials/pils.json`. The format follows `docs/research/deps/MAPPING_CONTRACT.md` and the 600–1200 and 1200–1800 partials. Cross-line ids are marked with their line. Earlier-block ids are marked "0–600", "600–1200" or "1200–1800". `Requires (any)` groups are separated by `;`. Every prerequisite and precedent is dated strictly before its dependent (registry target years; adjusted years for earlier blocks). No year moves are proposed (`partials/pils_year_adjustments.json` is empty).

Iron and steel: `blast_furnace` (1200–1800) → `cast_iron_shot_firebacks` (1830) → `sand_flask_casting` (2214) → `metal_casting_feed_design` (2279). `co_fusion_steel` + `standard_bar_iron` → **`cementation_blister_steel`** (2016). `sea_coal_substitution` (ecology, 1200–1800) + `coal_fired_ironworking` → `coal_grading` (2194) → with `blast_furnace`, **`coke_firing`** (2220) → `refractory_furnaces` (2232). Blister steel + coke → **`steel_refining`** (crucible cast steel, 2282) → `metal_annealing_control` (2394). The coke-to-puddling chain is `coal_fired_ironworking` + `ore_roasting` → `reverberatory_furnace` (2186); `reverberatory_furnace` + `coke_firing` → **`puddling_furnace`** (2368) → `grooved_bar_rolls` (2371, with `rolled_metal_strip`). `finery_forges` is a precedent of puddling, not a requirement.

Guns and powder (shared with Security): `pit_cast_bells` + `black_powder` (security, 1200–1800) → `gun_barrel_founding` (1812), which Security's `hand_gun_tubes` (1822) and `powder_artillery` (1848) require. `nitre_earth_leaching` + `nitrate_cultivation` → `potash_saltpetre_works` (1846) → `recrystallised_saltpetre` (2084). `black_powder` + `water_ore_stamps` → `corned_powder_mills` (1851) → `powder_rock_blasting` (2054). `jig_filed_gunlocks` (2381) requires Security's `flintlock_ignition`.

Engines: `rag_chain_mine_pumps` + `cam_motion_design` → **`flat_rod_mine_pumps`** (1958). With Knowledge's `vacuum_experiments` (2108) → **`steam_suction_pump`** (2198) → with `air_spring_law` (knowledge 2124), **`atmospheric_beam_engine`** (2226) → **`separate_condenser_engine`** (2341) → with Infrastructure's `cylinder_boring` (2342), **`rotative_steam_engine`** (2364) → `double_acting_engine` (2379) → with `puddling_furnace`, `pressure_vessels` (2399). Clocks: `verge_escapement_clock` + `edge_tempering` → **`mainspring_fusee_clocks`** (1858) → with `screw_cutting_lathe`, `gear_cutting_engine` (2138).

Textiles: `spinning_wheels` + `treadle_lathe_drive` → **`flyer_spinning`** (1940). `broad_treadle_loom` → **`flying_shuttles`** (2266). `flyer_spinning` + `flying_shuttles` → **`multi_spindle_spinning`** (jenny, 2328) → with `flyer_spinning`, **`roller_water_frame`** (2338); jenny + water frame → **`mule_spinning`** (2358). `knitted_loop_fabrics` + `wire_drawing` → **`stocking_knitting_frame`** (1990). Printing runs `textile_printing` → `mordant_printed_calico` (2144) → with Knowledge's `copperplate_preparation`, `copperplate_calico` (2304) → with `textile_calendering`, `roller_calico_printing` (2375).

Glass and ceramics: `potash_forest_glass` + `decolorized_clear_glass` → **`clear_crystal_glass`** (1878); `sea_coal_substitution` + `crucible_glass_melting` → `coal_fired_glass_furnace` (2022); clear glass + coal furnace → **`lead_crystal_glass`** (2148) and **`cast_plate_glass`** (2176). `tin_opacified_glaze` → `polychrome_tin_glaze` (1882) → with `underglaze_cobalt_blue`, `blue_white_tin_glaze` (2040). `frit_stonepaste` + `clear_crystal_glass` → `soft_paste_porcelain` (1979) → `bone_ash_porcelain` (2388). Chemistry: `mineral_acid_distillation` + `sulfur_purification` + `potash_saltpetre_works` → `globe_oil_of_vitriol` (2272) → **`lead_chamber_acid`** (2295) → with `kelp_alkali`, **`salt_cake_soda`** (2385).

Contact-gated (`contact_required`): `cochineal_scarlet`, `sugar_loaf_refining`, `indigo_vat_dyeing` and `carroted_fur_felting`, each requiring Logistics' `transoceanic_contact_voyages` (1912), except sugar, which requires Nutrition's `island_cane_plantations` (1878).
