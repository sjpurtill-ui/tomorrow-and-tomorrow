# Infrastructure dependencies, years 1800–2400

Machine-readable source: `partials/pils.json`. The format follows `docs/research/deps/MAPPING_CONTRACT.md` and the 600–1200 and 1200–1800 partials. Cross-line ids are marked with their line. Earlier-block ids are marked "0–600", "600–1200" or "1200–1800". `Requires (any)` groups are separated by `;`. Every prerequisite and precedent is dated strictly before its dependent (registry target years; adjusted years for earlier blocks). No year moves are proposed (`partials/pils_year_adjustments.json` is empty).

Vaults, roofs and domes: `rib_vaults` → `lierne_net_vaults` (1805) → `fan_vaults` (1818). `crown_post_roofs` + `timber_roof_trusses` → **`hammer_beam_roofs`** (1828). `double_shell_domes` + `herringbone_plano_convex_brick` → **`centerless_great_dome`** (1860) → with `iron_tie_rods`, `dome_iron_chains` (2290).

Water: `piped_town_conduits` + `piston_force_pumps` → **`bridge_wheel_waterworks`** (1985) → `water_tower_cisterns` (2090), **`water_lifting_machine`** (2166, with Production's `flat_rod_mine_pumps`) and, with Production's `atmospheric_beam_engine`, `steam_waterworks` (2256). `bored_log_mains` + `blast_furnace` → **`cast_iron_water_mains`** (2128) → `pressure_pipe_jointing` (2396). `covered_sewers` → `vaulted_brick_sewers` (2204) → `culverted_town_streams` (2244). `flushed_latrines` (health, 600–1200) + `piped_town_conduits` → `flushing_privy_cistern` (1993) → `s_trap_water_closets` (2356).

Land from water: `post_windmills` (production) + `sluiced_polders` (ecology) → **`drainage_windmills`** (1848) → **`drained_lake_polders`** (2036) → **`fen_drainage_cuts`** (2066).

Canals, docks and roads: `canal_locks` (1200–1800) → **`mitre_lock_gates`** (1908) → `lock_staircases` (2158) → with `road_tunnels`, `canal_tunnels` (2162); `lock_staircases` → `puddled_clay_canal_lining` (2321); tunnels + lining → **`canal_river_aqueducts`** (2324). Logistics' `staircase_summit_canal` (2080) requires `mitre_lock_gates` and `reservoir_fed_summit_canals`. `mitre_lock_gates` + Logistics' `dry_dock_services` → **`enclosed_wet_docks`** (2230). `drained_intertown_roads` + `river_toll_stations` (logistics) → **`turnpike_trust_roads`** (2212) → with `aggregate_road_foundations`, **`layered_stone_road_beds`** (2350) → `road_rolling_maintenance` (2378).

Bridges and machines: `flat_segmental_bridges` → **`elliptical_arch_bridges`** (1974) → with Security's `engineer_officer_corps`, **`bridge_road_engineer_corps`** (2234) → `bridge_road_engineering_school` (2296); elliptical arches + Production's `coke_firing` → **`cast_iron_arch_bridge`** (2359) → **`iron_framed_fireproof_mill`** (2385). `timber_cofferdams` → **`bridge_pier_caissons`** (2276). Security's `solid_bored_cannon` + Production's `atmospheric_beam_engine` → `cylinder_boring` (2342); boring + Production's `screw_cutting_lathe` → **`precision_machinery`** (2371). `hydraulic_lime_binders` → `concrete_mix_design` (2314) → with `harbor_beacon_towers`, **`dovetailed_rock_lighthouse`** (2318).

Town and seat: `four_hall_courtyards` + `stone_merchant_houses` → `courtyard_palace_block` (1871); `old_text_recovery` (culture) + `geometric_design_rules` → `classical_order_proportions` (1886) → `symmetrical_villas` (1955); palace + villas → **`axial_palace_gardens`** (2124) → with Production's `mercury_tin_mirrors`, `mirror_gallery_halls` (2168). `fireproof_roof_ordinance` (security) + `stone_party_walls` → `fire_rebuilding_acts` (2134) → `building_line_regulation` (2300). `fixed_capital_archives` + `vaulted_undercrofts` → `fireproof_record_vaults` (2004) → with Institutions' `war_ministry_bureaus`, **`ministry_office_block`** (2353).
