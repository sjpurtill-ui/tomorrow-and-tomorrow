# Security dependencies, years 1200–1800

Machine-readable source: `partials/pils.json`. The format follows `docs/research/deps/MAPPING_CONTRACT.md` and the 600–1200 partials. Cross-line ids are marked with their line. Earlier-block ids are marked "0–600" or "600–1200". `Requires (any)` groups are separated by `;`. Every prerequisite and precedent is dated strictly before its dependent. No year moves are proposed (`partials/pils_year_adjustments.json` is empty).

Cavalry: `single_mounting_stirrup` → **`paired_stirrups`** (1300) → `high_bow_war_saddle` (1315). `two_handed_lancers` + `paired_stirrups` + `high_bow_war_saddle` → **`couched_lance_charge`** (1515) → `tournament_training` (1647). `domesticated_mounts` + `armored_riding` → **`mounted_remount_school`** (1250) → `multi_remount_riders`.

Armor: `mail_armor_fabrication` → `mail_underpadding` (1590) and, with `wire_drawing`, `full_mail_harness` (1627) → `great_helm` (1686, with `closed_helmet_greaves`) → `visored_helmet` (1784). `banded_plate_cuirass` + `full_mail_harness` → **`coat_of_plates`** (1742) → `plate_limb_defences` (1778).

Fortification: `contracted_circuit_walls` → `hilltop_citadel_towns` (1208). `wet_moats` + `engine_proof_walls` → **`triple_line_land_walls`** (1220). `ditch_palisades` + `defensive_ditch_siting` → **`motte_and_bailey`** (1478) → with `dressed_stone_masonry`, **`stone_keep_towers`** (1525) → precedent for `curtain_wall_flanking_towers` (1575) → `round_flanking_towers` (1654) → with it, **`concentric_castles`** (1727). `wall_top_hoardings` (1535) → `stone_machicolations` (1698).

Siege: `traction_stone_throwers` → `hybrid_counterweight_engine` (1605) → **`counterweight_engines`** (1667). `torsion_spring_engines` + `bolt_throwing_frames` → `springald_wall_engines` (1732).

Crossbows: `crossbow_mechanism` + `standard_trigger_locks` → `stirrup_cocked_crossbow` (1565) → `belt_hook_spanning` (1747) → with production `ratchet_motion_control`, `windlass_crossbow` (1781).

Fleets: `incendiary_missiles` + `piston_force_pumps` → **`siphoned_liquid_fire`** (1345, needs Bitumen; no powder). `three_banked_warships` + logistics `lateen_merchant_rig` → `spur_prow_galleys` (1358) → with `naval_arsenals`, **`series_built_war_galleys`** (1583). Logistics `open_sea_cargo_ships` + `floating_needle_compass` → **`ocean_sailing`** (1692). `high_sided_bulk_ships` → `ship_fighting_castles` (1704) → `pressed_merchant_fleets` (1722).

Powder chemistry: `incendiary_missiles` + ecology `nitre_earth_leaching` (1745) → `nitre_incendiary_mixtures` (1760) → **`black_powder`** (1787). `black_powder` also requires `sulfur_purification`, `charcoal` and one nitre source (`nitre_earth_leaching` or ecology `nitrate_cultivation`, 1775). It is chemistry only. No item in this line requires `black_powder` or any gunpowder weapon. The gunpowder gates on `hand_cannoneer` and `hand_cannon` are to be re-gated at bake time, as the registry notes say.

**`ocean_sailing` redate.** This row maps the 1692 placement. The game's 0–600 block still defines `ocean_sailing` at 560, so the consumer will reject the id as already defined until the bake-time redate in `bake_time_fixes` removes the old placement and its equipment gates.
